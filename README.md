# 달려서 가족 만나기

`game-prompt.md`의 기획을 바탕으로 만든 모바일 웹 무한 달리기 게임입니다.
외부 이미지/오디오 파일 없이 Canvas 2D와 Web Audio API만으로 동작하는 순수 정적
웹앱이라, 별도 빌드 없이 바로 열어서 플레이할 수 있습니다.

## 실행 방법

브라우저 보안 정책(모듈/폰트 로딩) 때문에 `index.html`을 파일로 직접 여는 것보다
간단한 정적 서버로 띄우는 것을 권장합니다.

```bash
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속 (모바일은 같은 네트워크의 PC IP로 접속)
```

## 조작

- 좌우 스와이프(또는 방향키 ← →): 3차선 중 차선 이동
- 위로 스와이프(또는 방향키 ↑ / 화면 하단 ▲ 버튼): 점프 — 바닥 장애물(돌무더기, 웅덩이) 회피
- 아래로 스와이프(또는 방향키 ↓ / 화면 하단 ▼ 버튼): 슬라이드 — 머리 높이 장애물(울타리) 회피

## 게임 규칙

- 체형(비만도)은 1(가장 날씬·최고 속도) ~ 10(가장 뚱뚱·최저 속도), 5단계에서 시작.
  - 좋은 음식(사과/당근/브로콜리/물)을 먹으면 1단계 날씬해지고 빨라짐.
  - 나쁜 음식(포도/초코케이크/사탕/도넛)을 먹으면 1단계 뚱뚱해지고 느려짐.
  - 10단계에 도달하면 즉시 게임 오버.
- 체력(HP)은 3칸. 장애물(돌무더기/웅덩이/울타리)에 부딪히면 체형과 무관하게 체력이 1칸
  줄고(피격 후 잠깐 무적 시간 있음), 체력이 0이 되면 게임 오버.
- 300m/600m/900m 지점에서 순서대로 동생 → 아빠 → 엄마를 만나 함께 달리게 되고,
  900m(엄마)까지 만나면 온 가족이 모이는 해피엔딩으로 게임이 클리어됩니다.

## 파일 구조

- `index.html` — 화면 구조(캔버스 + HUD + 시작/게임오버/클리어 오버레이)
- `style.css` — 반응형 모바일 스타일
- `game.js` — 입력 처리, 게임 루프, 절차적 렌더링(캐릭터/음식/장애물), 사운드(Web Audio)
- `game-prompt.md` — 이 게임을 만들기 전에 정리한 기획/프롬프트 문서
